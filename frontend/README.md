# gacha

A peaceful, airy, unofficial Kerala lottery result checker web application.

## Stack
- Vite + React 18 + TypeScript
- React Router v6
- Tailwind CSS with design tokens
- Framer Motion, Zustand, Recharts, canvas-confetti, Zod
- Fonts: Manrope (UI), DM Mono (ticket numbers)
- Vitest + React Testing Library

## Getting Started
```bash
cd frontend
npm install
npm run dev
```

## Running Tests
```bash
npm run test
```
